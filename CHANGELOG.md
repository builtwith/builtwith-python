# Changelog

## 0.1.0 — 2026-10-20

- Initial standalone Python 3.10+ SDK, typed sync/async HTTPX clients.
- Verified REST lookup, search, account, registry and bulk-domain methods.
- Lossless JSON responses, structured errors, opt-in retries and lazy pagination.
- Optional client integration with the existing BuiltWith MCP server; framework-neutral and optional AI examples.
- Credential-free tests, CI validation, wheel/sdist packaging and release guidance.
